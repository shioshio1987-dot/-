# Iron Cadence

トレーニングの記録・インターバルタイマー・体組成をまとめて管理する PWA（ホーム画面に追加して使えるアプリ）。
一度開けば **オフラインでも起動でき**、データは **端末の中だけ** に保存される。

- **今日** — 直近7日のボリューム／連続日数、その日のメニュー選択
- **記録** — セット・重量・レップの記録、推定1RM、バーベルのプレート内訳、セット完了で自動インターバル
- **タイマー** — タバタ（20秒／10秒 × 8）＋各種設定＋バックアップ
- **カレンダー** — 月ごとの実施状況と1日の内訳
- **ボディ** — 体重・体脂肪率の推移グラフ

---

## 公開する（GitHub Pages）

このリポジトリには Pages 用のワークフローが入っている。リポジトリ側で一度だけ設定すればよい。

1. GitHub でこのリポジトリの **Settings → Pages** を開く
2. **Source** を **GitHub Actions** にする
3. **Actions** タブで `Deploy to GitHub Pages` が緑になるのを待つ

完了すると `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる。
ワークフローは `main` とこの作業ブランチへの push で走り、手動実行（Run workflow）もできる。

> PWA は HTTPS（または localhost）でしか Service Worker が動かない。
> HTML ファイルを直接ダブルクリックして開くとオフライン機能とインストールは使えない。

### 手元で確認する

```sh
python3 -m http.server 8899
# → http://localhost:8899/ を開く
```

## ホーム画面に追加する

| 端末 | 手順 |
| --- | --- |
| iPhone / iPad | Safari で開く → 下部の共有ボタン → **ホーム画面に追加** |
| Android (Chrome) | 右上の ⋮ → **アプリをインストール** / **ホーム画面に追加** |
| PC (Chrome / Edge) | アドレスバー右端のインストールアイコン |

追加後はアドレスバーの無い全画面で起動し、機内モードでも動く。
アプリ内の **タイマー → アプリとして使う** にも同じ案内が出る。

## データの扱い

記録はすべて端末の `localStorage`（キー `ironcadence.v1`）に入る。外部へ送信されることはなく、
アカウントも通信も不要。そのぶん **ブラウザのデータを消すと記録も消える**。

**タイマー → データ** から、

- **書き出す** … 全データを `iron-cadence-YYYY-MM-DD.json` として保存
- **読み込む** … その JSON を読み込んで、いまの端末のデータを置き換え（確認あり）

機種変更のときは、旧端末で書き出したファイルを新端末で読み込めば移行できる。

## ファイル構成

```
index.html              アプリ本体（HTML / CSS / JS すべて）
manifest.webmanifest    アプリ名・アイコン・全画面表示の設定
sw.js                   Service Worker（オフライン用のキャッシュ）
icons/                  アプリアイコン（PWA / iOS / favicon）
fonts/                  Chakra Petch（欧文見出し用・latin サブセットのみ同梱）
tools/make_icons.py     アイコンの生成スクリプト
.github/workflows/      GitHub Pages への自動デプロイ
```

日本語は端末のシステムフォントで表示するため、フォントの追加ダウンロードは発生しない。

## 更新するとき

`index.html` などを変更したら、**`sw.js` の `VERSION` を上げてから** push する。

```js
const VERSION = 'v2';   // v1 → v2
```

これを上げないと、すでにインストールした端末が古いキャッシュを表示し続ける。
新しい版を取得すると起動中の画面にトーストが出て、次回の起動から反映される。
（記録中に勝手に再読み込みはしない。）

アイコンを作り直す場合:

```sh
pip install pillow
python3 tools/make_icons.py
```
