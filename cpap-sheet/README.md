# CPAP 患者管理シート（Google スプレッドシート用 v2.0）

CPAP を利用している患者さんを管理する Google スプレッドシート用のスクリプトです。
**入力するのは「患者一覧」と「マスタ」の2つのタブだけ**で、ほかのタブ（ダッシュボード・月別・週別・年別など）は自動で作られます。

| ファイル | 中身 |
| --- | --- |
| `Code.gs` | スクリプト本体（Apps Script の「コード.gs」に貼る） |
| `SidebarForm.html` | 新規登録・レポート期間の入力フォーム（Apps Script に「SidebarForm」という名前の HTML ファイルとして貼る） |
| `test/` | 動作確認用のテスト（スプレッドシートには入れません） |

---

## タブの構成

| タブ | 種類 | 内容 |
| --- | --- | --- |
| **患者一覧** | 入力 | 1人1行の台帳。下の「列」を参照 |
| **ダッシュボード** | 自動 | 現在の利用者数、今月・今週の導入と離脱、1年継続率、機器別・業者別の人数、直近の導入・離脱、**要確認（入力もれ・矛盾の一覧。行番号をクリックするとその行へ移動）**、グラフ |
| **月別** | 自動 | 月ごとの導入数・離脱数・純増・月末の利用者数、機器別・業者別の導入数（新しい順） |
| **週別** | 自動 | 週（月曜〜日曜）ごとの同じ表 |
| **年別** | 自動 | 年ごとの同じ表とグラフ |
| **機器別一覧** | 自動 | 機器・業者・状態を選ぶと、その人たちの一覧（レポート期間つき）。レポート期間が空欄の人は水色 |
| **離脱分析** | 自動 | 離脱理由別・利用期間別（3ヶ月未満〜3年以上）・機器別の離脱、導入年ごとの継続率（3ヶ月・1年・2年）、離脱した人の一覧 |
| **台数・費用** | 自動 | 業者ごと・月ごとの利用台数とレンタル料の目安（請求書の確認用） |
| **マスタ** | 入力 | 機器と業者の組み合わせ（メーカー・クラウド・月額・初月無料）、離脱理由の候補 |
| **使い方** | 自動 | シートの中で読める説明 |
| 匿名データ | 必要なとき | 名前・備考を除いた一覧（メニューから作成）。外部での分析や AI に渡すときに使う |

自動のタブには名前を出していません（機器別一覧だけは作業用に名前を出します）。

## 患者一覧の列

| 列 | 入力 | 説明 |
| --- | --- | --- |
| ID | 自動／手入力 | 名前を入れると次の番号が入る（ID がすべて数字のとき） |
| 名前 | 手入力 | 同じ名前が複数あるとオレンジ色（同姓同名なら問題なし） |
| 機器 | ドロップダウン | マスタの機器から選ぶ |
| 業者 | ドロップダウン | 業者が1社だけの機器は自動で入る。複数ある機器（AirSense10 など）は選ぶ |
| レポート開始日・レポート終了日 | 日付 | レポートを出す期間。まとめて入れることもできる（下記） |
| 導入日 | 日付 | 月別・週別の「導入数」はこの日で数える |
| 離脱日 | 日付 | 入れると状態が「離脱」に。未来の日付なら、その日になったときに切り替わる |
| 備考 | 手入力 | 自由記入 |
| 状態 | 自動 | 利用中／離脱。離脱日から自動で決まる（離脱日を消すと利用中に戻る） |
| 離脱理由 | ドロップダウン | **追加した列**。自己中断・移管/転院・経済的な理由など。離脱分析で使う（候補はマスタで変更可） |

- 日付は `t`（今日）、`y`（昨日）、`20261001`、`R8.10.1`、`10/1`、全角数字でも入ります。ダブルクリックでカレンダーも出ます。
- 赤：直してほしいもの（入力もれ・ID の重複・日付として読めない・日付の前後が逆）／オレンジ：確認してほしいもの／グレー：離脱した人。
- 1行目の見出しは保護しています（名前を変えると集計できなくなるため。警告が出るだけで編集はできます）。

## 導入手順（いまのスプレッドシートに入れる場合）

URL と共有設定がそのまま使えるので、いまのファイルに入れるのがおすすめです。旧バージョンの「ALL」「設定」シートは**読むだけで変更しません**。

1. **バックアップ**：［ファイル］→［コピーを作成］で、いまのファイルのコピーを取っておきます。
2. **スクリプトを入れ替える**：［拡張機能］→［Apps Script］を開き、
   - 「コード.gs」の中身を**すべて消して**、`Code.gs` の中身を貼り付けます（古いコードを残すと関数名がぶつかります）。
   - 「SidebarForm」（HTML）の中身を `SidebarForm.html` の中身に置き換えます。ない場合は［＋］→［HTML］で `SidebarForm` という名前で作ります。
   - 保存（Ctrl+S）します。
3. **スプレッドシートを再読み込み**すると、メニューに［CPAP管理］が出ます。
4. ［CPAP管理］→［管理・設定］→［**初期セットアップ／修復**］を実行します。
   - 初回は Google の承認画面が出ます（このファイルだけを扱う権限です）。
   - 「旧バージョンの ALL シートが見つかりました。取り込みますか？」で［はい］を押すと、ALL の患者データが「患者一覧」に入ります。旧「設定」の料金も［マスタ］に入ります。
5. ［**マスタ**］を確認します。月額レンタル料・初月無料を入れると「台数・費用」に金額が出ます。
6. 必要なら［管理・設定］→［**旧バージョンのタブを非表示にする**］で、ALL・設定・集計・機種別タブなどを隠します（削除はしません。画面下のタブ一覧から戻せます）。

新しいファイルで始める場合は、空のスプレッドシートで 2〜4 を行います。旧データを使うときは、旧ファイルの ALL（と設定）タブを右クリック →［コピー先］→ 新しいファイル、としてから［旧バージョンのデータを取り込む］を実行してください（「ALL のコピー」という名前のままで大丈夫です）。

### 取り込みのときの変換

| 旧（v17 の ALL） | 新（患者一覧） |
| --- | --- |
| 管理ID・名前・CPAP機種・仕入先 | ID・名前・機器・業者（「会社名\|機種名」は会社名だけに） |
| 開始日・終了日 | レポート開始日・レポート終了日（`=TODAY()-1` の式は、その時点の日付で入ります） |
| 導入日・離脱日・その他 | 導入日・離脱日・備考 |
| 状態「移管」 | 状態「離脱」＋離脱理由「移管・転院」 |
| 状態「離脱」（理由なし） | 離脱理由「不明」（あとで直せます） |
| 状態「予定」 | 利用中 |
| 最終通院日・次回予定日・対象・クラウド区分・自動計算の列 | 取り込みません（旧 ALL シートにそのまま残ります） |

何度実行しても、すでに患者一覧にいる人（同じ ID、または同じ名前＋導入日）は飛ばします。

## 毎日の使い方

- **新しい人**：［CPAP管理］→［新規登録フォーム］。または患者一覧のいちばん下に直接入力。
- **やめた人**：離脱日を入れて、離脱理由を選ぶ。行は消さずに残す（過去の集計が変わらないように）。
- **一度やめて再開した人**：新しい行で登録し、備考に前の ID を書く。
- **レポート期間をまとめて入れる**：患者一覧で行を選び（見出しの ▼ で機器を絞り込んでから選ぶと便利）、［CPAP管理］→［レポート期間をまとめて入力］。
  「先月」「今月（1日〜昨日）」「前回の続き（前回の終了日の翌日から）」「日付を指定」から選べます。離脱した人と、絞り込みで隠れている行には入りません。
- **集計**：入力から10分ほどで自動更新されます。すぐ見たいときは［CPAP管理］→［集計を今すぐ更新］。

## 自動更新のしくみ

初期セットアップで、10分ごとに動くトリガーを1つ作ります。患者一覧・マスタ・日付が前回から変わっていないときは何もしません。
トリガーはセットアップした人のアカウントで動きます。その人がこのファイルを使えなくなったら、別の人が［管理・設定］→［自動更新をオンにする］を実行してください。
旧バージョンの「毎日7時の自動更新」トリガーは、セットアップのときに新しいものへ置き換えます。

## 旧バージョン（v17）から変わったこと

| | v17 | v2.0 |
| --- | --- | --- |
| タブの数 | 約20（機種ごとのタブを含む） | 10（入力は2つだけ） |
| メニュー | 20項目以上 | 4項目＋管理用のサブメニュー |
| 集計のしかた | 数式（ARRAYFORMULA・COUNTIF）とスクリプトが混在。列を消すと #REF! | スクリプトで計算した値を書き込む。#REF! が出ない |
| 列の探し方 | 見出しの前方一致（「ID」が「ID重複」に当たるなどのずれが起きた） | 完全一致。見つからないときは分かるように知らせる |
| 状態 | 「その他」に“移管”と書いてあるかで判定 | 離脱日で決まる。移管は「離脱理由」で区別 |
| 入力チェック | データチェックタブで件数だけ | ダッシュボードに一覧。行番号をクリックでその行へ |
| 機種別タブ | 機種×業者ごとにタブ（9枚） | 「機器別一覧」1枚で、機器・業者・状態を選んで切り替え |

**今回の列構成に入れていないもの**（必要ならあとから足せます）

- 最終通院日・次回予定日と「最終通院日から3ヶ月で黄色」の表示
- 対象（○）の列 … 代わりに「レポート期間が入っている人」が対象という扱いです（`getPatientsForBatch()` の `target` もこの基準）
- 税抜／税込の両方の入力と整合チェック、月額収入 … 月額は税込だけにしました

> このリポジトリは公開されているため、旧スクリプトにあった仕入先ごとの料金はここには入れていません。
> 旧「設定」シートから取り込むか、［マスタ］に入力してください。

## よくある質問

**Q. 集計タブに書き込んでしまった。**
次の更新で上書きされます。書き込もうとすると警告が出るようにしてあります。

**Q. 列を追加したい。**
患者一覧の右端に足すのは大丈夫です。見出しの名前で列を探しているので、既存の列名だけは変えないでください。
列を並べ替えたあとは［初期セットアップ／修復］を一度実行してください（色分けとドロップダウンを付け直します）。

**Q. ドロップダウンに新しい機器・業者を出したい。**
［マスタ］に1行足すと、すぐに患者一覧のドロップダウンに出ます。

**Q. 自分で作った「ダッシュボード」などのシートがあった。**
同じ名前のシートがあると、消さずに「ダッシュボード（旧）」に名前を変えて残します。

## 開発者向け：テスト

Apps Script はここでは動かせないので、`test/gas-mock.js` に Apps Script（スプレッドシート）の必要な部分をまねたものを作り、その上で `Code.gs` をそのまま動かして確かめています。
本物と同じ条件でエラーになるようにしてあります（`setValues` の行数・列数の不一致、0行の範囲、シートの外、結合セルの一部だけの結合や固定、未実装のメソッドの呼び出しなど）。

```sh
node test/run-tests.js                      # 6つのシナリオ（タイムゾーンの違いも含む）
TZ=Asia/Tokyo node test/sidebar-test.js     # サイドバーをブラウザで操作（Playwright が必要）
TZ=Asia/Tokyo node test/render-preview.js preview.html   # 架空データで各タブの見た目を HTML に
```

期待値はテスト側で別に計算しています（月別・週別・年別の数字、カード、機器別、離脱、台数・費用など）。
